## 1. AI 캠퍼스 사업부 추가

- **무엇을**: 제작 요청 폼과 시스템 전체에 "AI 캠퍼스"를 KDT/KDC와 나란히 추가
- **왜**: 현재 코드에는 KDT/KDC/기타만 있어 AI 캠퍼스 강의를 만들 수 없음 (확인함)
- **어떻게**:
  - 제작 요청 폼 사업부 선택에 **"AI 캠퍼스"** 추가, KDT처럼 **트랙 선택**(Private LLM / Fullstack AX / Data Science / On-Device / Physical / UXUI) 표시
  - 샘플 AI 캠퍼스 강의 1~2개를 목 데이터에 추가해 화면에서 바로 보이게
- **확인**: 폼에서 AI 캠퍼스 선택 → 트랙 고르기 → 제출 시 목록·상세에 정상 표시
- `개발자 메모`: `BusinessUnit` 타입에 `"AI 캠퍼스"` 추가(`lib/types.ts:9`), `AI_CAMPUS_TRACKS` 상수 신설(`lib/constants.ts`), 폼 Q3 라디오 분기(`project-request-form.tsx:366`), `FormData`/`isComplete`에 `aiCampusTrack` 반영. (D2 따라 `Project.courseCode?`, D3 따라 `contentBranch?` 필드)

## 2. AI 캠퍼스 전용 제작 단계 (가장 큰 작업)

- **무엇을**: AI 캠퍼스 강의는 **촬영·편집·자막을 빼고** `교안 → 검수 → 승인 → 완료`로
- **왜**: D1에서 확정. 영상 제작이 없는 교안 중심 강의이기 때문
- **어떻게**:
  - 작업현황 표를 일반 6열 대신 **교안/검수/승인/완료 4열**로
  - 일정표·진척표에서 AI 캠퍼스 행은 촬영·편집 칸을 비우거나 "—"로
  - 교안 링크 등록되면 **촬영·편집을 건너뛰고 바로 검수로** 넘어가게
  - 슬랙 알림도 촬영·편집 완료 메시지는 보내지 않게
- **확인**: AI 캠퍼스 강의 상세에서 촬영·편집 단계가 안 보이고, 교안 등록 → 검수로 바로 이동
- `개발자 메모`: 사업부별 단계를 **단일 상수(source of truth)**로 두고 컴포넌트가 조회하도록 — `getStagesForBusinessUnit(bu)` 신설, `getEffectiveKanbanColumn()` 분기(`process-helpers.ts`), `work-status-tab.tsx`·`monday-board.tsx`·진척 매트릭스·슬랙 템플릿 각각 분기. 코드량 큼.

의견 : 교안단계도 뺏어 메인 대시보드에서 진행 중인 강의에서는 교안, 검수, 승인, 완료를 제외한 다른 단계는 빗금같은걸 쳐서 주는건 어때? 아니면 이거 어떻게 하면 거기가 비활성화되어있다는걸 한눈에 그리고 너무 거슬리지않고 세련되게 ui 로 표시할 수 잇는지 ㅎ나번 의견을 줘봐

## 3. 장(章) 이름 클릭해서 바로 고치기

- **무엇을**: "N장 + 장 제목"을 클릭하면 그 자리에서 글자를 고칠 수 있게 (예: 프로젝트 / 문서 / 해설 영상)
- **왜**: 노션 요청 사항. 장 단위가 영상이 아닌 형태로 다양해지는 경우 대응
- **어떻게**: 제목 클릭 → 입력칸으로 바뀜 → 수정 후 저장. **내부 화면에서만**(D4), 외부 읽기 전용 화면에서는 비활성
- **확인**: 내부 화면에서 장 제목 수정·저장되고, 외부 화면에서는 클릭해도 안 바뀜
- `개발자 메모`: `work-status-tab.tsx` 장 헤더(~189, 380) 인라인 편집 전환, 부모 `page.tsx`의 `chapterTitles` 업데이트 콜백, `readOnly` 분기. 일정 탭 헤더도 적용할지는 D4 확정 후 결정.

## 4. 교안 링크 업로드 권한 변경

- **왜**: 노션 요청 사항 (현재는 "커기매만 직접 입력")
- **어떻게**: **D5 답변에 따라** 허용 대상 결정 후 권한 분기 적용
- **확인**: 허용된 역할에서만 교안 셀 입력칸이 보임
- `개발자 메모`: 작업현황 탭 교안 셀 인라인 입력 모드의 역할 노출 점검·수정, 정책 문서 RL- 갱신.
